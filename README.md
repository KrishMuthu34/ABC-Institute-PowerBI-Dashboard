# ABC Institute: Student and Course Analysis (Power BI)

An interactive Power BI dashboard analyzing student enrollment,
course fees and certificate issuance for a training institute (2021-2023).

## Dashboard
![Dashboard](screenshots/dashboard.png)

## Key Numbers
- 702 students | Rs. 5.48M total fees | 7 courses
- 504 students issued certificates

## Tools Used
Power BI, Power Query, DAX

## What I Did
1. Combined 3 yearly files (2021, 2022, 2023) into one table
2. Cleaned data in Power Query (fixed course name typos, date formats)
3. Built a data model with relationships between Personal Details
   and Student Course Details
4. Created DAX measures (e.g., Certificates Issued)
5. Designed visuals: fees by course, enrollments by month,
   enrollments by age group, certificate gauge
6. Added Year, City and Course slicers

## Insights
- Enrollments peak in April (117) and September (122)
- Adobe After Effects and Autodesk 3Ds Max are the top-earning courses
